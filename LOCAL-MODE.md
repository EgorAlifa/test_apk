# Локальный режим: шоу с ноутбука ведущего

Если интернет на празднике слабый или публичные серверы сообщений тормозят, ноутбук ведущего может сам
раздавать игру гостям по Wi-Fi. Гости в той же сети Wi-Fi подключаются к ноутбуку напрямую, а гости
с мобильным интернетом — как обычно, через интернет. Оба способа работают одновременно.

## 1. Один раз: подготовка

1. Установите **Node.js LTS** с сайта <https://nodejs.org> (большая зелёная кнопка «LTS», установка
   с настройками по умолчанию).
2. Скачайте проект:
   - на странице репозитория GitHub нажмите **Code → Download ZIP** и распакуйте архив в любую папку
     (например, на рабочий стол); **или**
   - `git clone https://github.com/egoralifa/test_apk.git`
3. Важно: в папке должны быть файлы `video.mp4.part0` … `video.mp4.part4` — это видео шоу.

## 2. На празднике

1. Подключите ноутбук к Wi-Fi праздника — к **той же сети**, к которой подключатся гости.
2. Запустите сервер двойным щелчком:
   - Windows: `start-windows.bat`
   - Mac: `start-mac.command` (если macOS не даёт открыть: правый щелчок → «Открыть» → «Открыть»)
3. Если Windows спросит про брандмауэр — поставьте галочку **«Частные сети»** и нажмите
   **«Разрешить доступ»**. Без этого телефоны не смогут подключиться.
4. В окне появится адрес вида `http://192.168.1.5:8080/`. **Откройте этот адрес в браузере на ноутбуке
   ведущего** (Chrome, Edge или Safari). Не закрывайте чёрное окно сервера до конца праздника.
5. Гости сканируют QR-код с экрана: большой — «Wi-Fi праздника», маленький — для тех, кто на мобильном
   интернете.

Чтобы остановить сервер — закройте его окно (или нажмите Ctrl+C).

## Как узнать IP-адрес ноутбука

Сервер сам печатает адреса при запуске. Если адресов несколько, нужен тот, что из сети Wi-Fi (обычно
начинается с `192.168.` или `10.`). Вручную:
- Windows: Пуск → `cmd` → команда `ipconfig`, строка «IPv4-адрес» у адаптера беспроводной сети.
- Mac: Системные настройки → Wi-Fi → «Подробнее…» → IP-адрес.

## Если что-то не работает

**Телефоны не открывают страницу:**
- Телефон точно в той же сети Wi-Fi, что и ноутбук? Мобильный интернет на телефоне не подойдёт для
  локального адреса — такие гости пусть сканируют маленький QR-код.
- **Гостевая сеть** роутера часто запрещает устройствам видеть друг друга («изоляция клиентов»).
  Подключите ноутбук и гостей к основной сети или отключите изоляцию в настройках роутера.
- **Брандмауэр**: на Windows откройте «Брандмауэр Защитника Windows» → «Разрешение взаимодействия
  с приложением…» и включите **Node.js** для частных сетей. Также проверьте, что сеть Wi-Fi в Windows
  помечена как «Частная», а не «Общедоступная». Сторонний антивирус тоже может блокировать — разрешите
  Node.js. На Mac: Системные настройки → Сеть → Брандмауэр → разрешите входящие подключения для node.
- Проверьте адрес: на ноутбуке откройте тот же адрес `http://192.168.x.x:8080/` — если и там не
  открывается, сервер не запущен (смотрите сообщения в его окне).

**«Node.js не найден»** — установите Node.js LTS с <https://nodejs.org> и запустите скрипт снова
(после установки иногда нужно перезагрузить компьютер).

**«Порт 8080 уже занят»** — закройте другое окно сервера; или запустите на другом порту:
`PORT=8081 node server.js` (Mac) / `set PORT=8081 && node server.js` (Windows).

**Видео не играет** — проверьте, что в папке есть все пять файлов `video.mp4.part0` … `part4`.
